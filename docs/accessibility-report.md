# Accessibility Report

## Scope
- Core user journeys: Services, Contact, Careers, Insights.

## Findings
- Required form fields have labels and error messages.
- Interactive accordion controls expose expanded state.
- Key pages use semantic sectioning and heading structure.

## Actions Completed
- Global loading, error, and not-found fallback states added.
- Accessibility review checklist documented.

## Next Steps
- Add screen-reader flow testing with NVDA/VoiceOver.
- Add keyboard trap audits for all modal-like interactions.
